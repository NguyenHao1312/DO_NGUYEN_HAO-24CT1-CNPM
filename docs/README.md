# 📚 Tài Liệu Dự Án UniMS

Đây là thư mục chứa các tài liệu thiết kế và kiến trúc của dự án UniMS.

## Danh sách tài liệu

- [Activity Diagram](./ActivityDiagram.md)
  Sơ đồ hoạt động (Activity Diagram) mô tả luồng nghiệp vụ của hệ thống.
  
- [Diagram](./Diagram.md)
  Các sơ đồ thiết kế tổng quan, bao gồm sơ đồ lớp (Class Diagram) và sơ đồ cơ sở dữ liệu.
  
- [Mermaid Diagrams](./Mermaid.md)
  Tập hợp các sơ đồ được biểu diễn dưới dạng Mermaid code để dễ dàng nhúng và render trực tiếp trên GitHub/Markdown.
